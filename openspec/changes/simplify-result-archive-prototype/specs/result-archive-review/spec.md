# Spec Delta

## Purpose

让审阅者先通过简单按钮体验读取结果与采集状态，再按需查看字段证据、故障场景和内部记录。此能力只约束可丢弃的审阅附件，不定义 AIDB 生产功能、归档完整性标准或自动触发保证。

## ADDED Requirements

### Requirement: 默认突出读取结果主流程

原型 SHALL 默认展示读取主操作、结果摘要和独立的采集状态；七组场景、故障开关、内部计数与完整字段列表不得常驻默认页面。

#### Scenario: 首次打开
- **WHEN** 审阅者首次打开或刷新原型
- **THEN** 可以直接点击读取按钮，并在操作后区分结果可用和采集状态
- **AND** 不需要先挑选故障场景或核对内部字段

### Requirement: 按需查看细节且保留状态

原型 SHALL 提供明确的细节入口，保留原有场景、环境开关、字段对照和证据；展开或收起不得重置记录、采集次数或当前场景。

#### Scenario: 保存后查看细节
- **WHEN** 审阅者保存结果后展开细节，再收起细节
- **THEN** 已有记录和采集状态保持一致，主流程可以继续操作

### Requirement: 隐藏工具不得隐藏真实问题

原型 SHALL 在简洁页面说明本次数据库错误、未采集或读取标签缺失，不将主要末态保存宣称为完整归档，也不得因减少展示删除原状态转换行为。

#### Scenario: 数据库不可用
- **WHEN** 审阅者在细节中断开数据库，收起细节后读取
- **THEN** 结果可用与采集失败分开显示，恢复连接本身不自动补存

#### Scenario: 绕过采集或改走底层读取
- **WHEN** 直接解析没有触发采集，或底层读回缺少单位标签
- **THEN** 简洁页面分别提示未采集或标签缺失，并允许查看原因

### Requirement: 共享边界与导出范围准确

原型 SHALL 单文件离线运行并标明内存模拟；公共附件不得包含个人绝对路径、用户数据库或原始计算文件。本轮不新增字段或 JSONL 数据导出，不改动四类主动操作原型；体验记录导出可在细节中保留。

#### Scenario: 下载并分享
- **WHEN** 他人下载 HTML 后用浏览器打开
- **THEN** 无需安装或连接数据库即可体验，能够区分真实样本、合成补证和模拟动作
- **AND** 导出体验记录仅保存本页操作，不宣称是材料数据导出
