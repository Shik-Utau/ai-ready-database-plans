# Design

## Context

原型来源为 MatCreator 02 II 单文件 HTML（原型提交 775dea9），内嵌工单 07 的已有实跑证据，行为在内存模拟。用户确认减少展示、保留行为，因此只调整展示层，不重新设计采集或重试策略。

## Goals / Non-Goals

**Goals:** 默认页面可直接读取并看到结果与保存状态；展开后仍可审阅全部现有行为；同一份 HTML 离线可用。

**Non-Goals:** 不修复 AIDB、不执行真实计算或数据库实验、不删减其他原型的导出功能，不将“主要末态已保存”提升为“完整归档已验收”。

## Decisions

- 保留原状态转换模块，增加简洁展示层。相较重写逻辑，这样更容易核实本轮只是展示调整。
- 默认使用单一聊天/结果区和一个主按钮；“查看细节”恢复场景标签、内部状态和故障操作。保留当前场景与记录，展开/收起均不重置业务状态。
- 正常结果只保留能量、原子数与保存状态，明确“仅保存末态”。数值标签缺失、数据库错误、未采集等条件在简洁页面仍可见，详细原因按需查看。
- 继续采用逻辑原型，不新增多套外观切换，避免增加用户此次希望减少的选项。单文件无依赖、无网络请求，保持按钮驱动。
- 共享版把个人文件系统前缀替换为说明性占位符，计算值、字段名和差异不变。原始完整报告留在本地，共享报告独立说明证据限制。

## Risks / Trade-offs

- 细节收起后不易发现 → 固定保留“查看细节”，出现问题时给出直接入口。
- 状态简化可能误导 → 计算结果与采集状态分开显示，不显示笼统“全部完成”。
- GitHub 文件页无法执行 HTML → README 提供下载方式，注明保存后浏览器打开。
- 未合并的其他原型 PR 也修改仓库说明 → 本分支只关联 02，不修改那个分支；合并时保留双方附件入口。
