## 打开与操作

打开 [index.html](index.html)，在 GitHub 文件页选择 Download raw file，保存后用浏览器打开。单文件离线运行，无需安装依赖或连接数据库；GitHub 文件页只展示源码，尚未启用 Pages。

1. 默认已选第一个问题，直接点击中间橙色的“执行第 1 步”。
2. 看“刚刚发生了什么”和状态观察，再按新的橙色按钮继续。路线标出已操作、当前和后续步骤，并说明本步是否写入。
3. “查看回复与结果 / 查看字段差异 / 查看操作历史”只切换内容，不执行请求，也不推进步骤。
4. 想自行对照时展开“自由试验”。与当前推荐步骤相同的动作会推进路线，其他动作会提示路线尚未推进。
5. 体验结束后可留下判断或导出体验记录。切换问题和重新体验会清空本场景的模拟记录，展开或收起工具不会清空。

第一个问题的路线是：读取并尝试保存 → 查询是否保存 → 比较保存前后。查询不会补存，恢复连接不会自动重试。“已操作”不代表保存成功，更不代表完整归档通过。
