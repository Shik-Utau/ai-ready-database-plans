# Spec Delta

## Purpose

让非开发者能在完整的结果归档原型中知道从哪里开始、下一步做什么、不同按钮如何影响状态，并通过现有七个场景理解字段与归档问题。此能力只约束内存模拟的审阅附件，不规定生产实现或业务归档标准。

## ADDED Requirements

### Requirement: 完整原型提供清晰操作路线
原型 SHALL 恢复原完整场景与状态展示，默认选定第一个问题，展示本场景全部步骤、当前步骤、唯一推荐下一步及其作用；已操作不得被描述为保存成功。

#### Scenario: 首次进入并完成第一步
- **WHEN** 审阅者打开原型并点击推荐动作
- **THEN** 能看到实际回复和状态变化，路线指向下一步，并说明下一步是否写入

### Requirement: 查看与自由试验关系明确
原型 SHALL 将查看结果、查看字段和操作历史与执行请求分开；自由试验按作用分组，说明写入、只读、切换入口和切换环境的差别。

#### Scenario: 查看字段及历史
- **WHEN** 审阅者切换查看标签
- **THEN** 读取次数、采集次数和记录数不变，推荐步骤不被自动执行

#### Scenario: 自由试验偏离路线
- **WHEN** 审阅者执行了不同于推荐下一步的动作
- **THEN** 原行为执行并显示状态，但路线不跳过未执行步骤，页面说明尚待进行的推荐动作

### Requirement: 状态保留与重置有明确边界
原型 SHALL 保留原有七个场景与底层行为，展开或收起辅助工具不改变状态；场景切换和重置明确说明会清空本场景模拟记录。失败、未采集、读取标签缺失必须有可见反馈。

#### Scenario: 故障恢复
- **WHEN** 数据库不可用时读取，再恢复连接
- **THEN** 结果保留、采集失败分开显示，恢复连接本身不自动补存

#### Scenario: 展开与切换场景
- **WHEN** 审阅者展开或收起工具，再选择另一个场景
- **THEN** 展开收起不改变状态，明确标注的场景切换才从该场景初始状态重新开始

### Requirement: 共享及导出边界准确
原型 SHALL 单文件离线运行并标明内存模拟，公共附件不含个人绝对路径、用户数据库或原始计算文件；不新增字段和 JSONL 数据导出，保留体验记录导出，不改四类主动操作原型。

#### Scenario: 分享与下载
- **WHEN** 他人下载 HTML 并导出体验记录
- **THEN** 无需安装或连接数据库即可体验，导出记录仅包含本页操作，真实样本与合成证据明确区分
