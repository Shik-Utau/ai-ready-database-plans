# Proposal

## Why

02 完整原型的按钮缺少关系说明，用户不清楚先后顺序以及查看、执行、环境切换的区别。2026-11-09 用户在看过简洁版后，明确要求回到上一版完整原型，并让人容易理解如何操作。本轮继续解决操作负担，方式改为清晰引导与操作分组。

## What Changes

- 从原完整原型 775dea9 恢复布局与七个场景；保留纯状态模型和证据值。
- 中间展示完整操作路线、当前位置、唯一推荐下一步，以及该步的作用和观察重点。
- 查看结果、字段与执行记录使用明确的查看标签；自由操作按写入、只读、入口/环境和判断分组，说明是否改变数据。
- 状态始终可查看；折叠辅助工具不清空状态。场景切换及重置明确说明会重新开始。
- 02 没有字段或 JSONL 数据导出，仍保留体验记录导出；不修改四类主动操作原型。
- 更新同一 GitHub 审阅分支、说明和 OpenSpec，单文件离线运行、内存模拟和真实/合成边界不变。

## Capabilities

### New Capabilities

- result-archive-review: 结果归档审阅原型的操作引导、状态观察与共享边界。

### Modified Capabilities

无。完整归档的业务标准仍未获批。

## Impact

仅影响 docs/prototypes/result-archive、相应仓库入口及本变更文档。原简洁版保存在历史提交 c46fbe3，当前入口改为完整引导版。关联 [原业务规划](../plan-aidb-three-flows/proposal.md)，不实施生产功能。
