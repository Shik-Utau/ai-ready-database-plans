# Proposal

## Why

02 结果归档原型同时展示七组场景、故障开关、内部计数和字段对照，主流程不够突出。用户于 2026-11-09 确认只调整 02，先减少展示、保留底层行为，并延续将原型上传 GitHub 供他人观察的要求。

## What Changes

- 默认只呈现读取结果、计算结果和保存状态；详细审阅工具按需展开。
- 数据库不可用、底层单位缺失等问题发生时保留明确反馈，不通过隐藏展示改变行为或伪装成功。
- 保留七个场景、字段对照、原始证据、体验记录导出，但不常驻主流程。
- 02 原型没有字段导出或 JSONL 数据导出。本次不新增这两项，也不改四类主动操作原型或否定其他导出能力。
- 发布可离线打开的 HTML、简洁报告和查看说明；公共附件替换个人绝对路径，保留证据值和真实/合成边界。

## Capabilities

### New Capabilities

- `result-archive-review`: 结果归档审阅原型的主流程、按需展开和共享边界；仅约束审阅附件。

### Modified Capabilities

无。已有三业务线规划仍是讨论稿，业务归档范围没有因此获批。

## Impact

仅涉及本规划仓库 `docs/prototypes/result-archive/` 与本变更文档，以及必要的仓库入口说明。用户明确授权 HTML 审阅附件，作为原“只放规划文档”约定的有限扩展；不包括生产代码、用户数据库或原始计算文件。

关联：[原业务规划](../plan-aidb-three-flows/proposal.md)和[计算后采集讨论稿](../plan-aidb-three-flows/specs/aidb-result-collection/spec.md)。不更改其业务待决任务或四类主动操作 PR。
