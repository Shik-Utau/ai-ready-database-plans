# 02 结果归档：简洁原型

本轮只修改 02 结果归档。用户已确认：减少展示，保留底层行为。要观察的是：读出结果后，能否分清结果是否可用、是否保存，以及保存了哪些内容。

## 打开方式

打开 [index.html](index.html)，在 GitHub 文件页选择 Download raw file，保存后用浏览器打开。单个文件即可运行，无需安装依赖、启动服务或连接数据库。GitHub 文件页只展示源码，本仓库尚未启用 Pages。

首次打开只显示读取按钮。点击后显示能量、原子数和保存状态；“查看保存范围”解释为什么末态保存不等于完整归档。“查看细节”可展开七个对照场景、字段差异、故障开关及体验记录导出。展开和收起不会清空状态；切换场景或重置场景会重新开始。

## 这次改了什么

- 默认单栏展示主流程，把流程图、状态表、重复操作和证据工具放到细节中。
- 故障发生时仍在主界面提示原因；结果保留、去重和恢复逻辑保持原样。
- 02 没有字段/JSONL 数据导出入口。保留细节中的体验记录 JSON 导出，不修改“四类主动操作”原型。

按钮演示均为内存模拟。数值来自 07 已保存的 Si 和合成记录快照；合成值不证明真实磁性或 +U 输出已跑通。关闭页面不会写入真实数据库。
