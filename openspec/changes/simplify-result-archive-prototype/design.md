# Design

## Context

用户已大致理解 07 的问题，当前难点是完整原型中各按钮的操作关系。按最新要求从原型提交 775dea9 恢复，撤回上一轮默认单栏简洁展示；简洁版保留在 Git 历史。

## Goals / Non-Goals

**Goals:** 不看外部说明也能从默认场景开始，知道每步做什么、哪里看变化，以及辅助按钮与推荐步骤的关系。

**Non-Goals:** 不改变采集、去重、故障恢复等状态转换；不执行真实数据库实验，不批准业务归档范围。

## Decisions

- 继续使用单文件逻辑体验原型。恢复完整布局与场景，而非增加多种外观候选，避免与用户指定的回退方向冲突。
- 中间上方放操作路线：步骤有已操作、当前、待操作的标记；唯一推荐动作附效果说明与观察位置。完成表示操作走完，不表示保存成功或业务验收。
- 主操作与自由试验共用原状态模型。手动操作与下一引导动作相同才推进路线；其他操作明确提示没有推进推荐步骤。
- 字段与操作历史标签只用于查看，不执行写入；自由试验把读取并尝试保存、只读检查、入口/环境变化分组。保留每项动作，辅助区可折叠且状态不重置。
- 状态观察区持续呈现读取次数、采集次数、记录数、回执和查询；中间附本次变化摘要。故障、未采集和标签缺失继续可见。
- 不改纯模型字节。保留原证据脱敏方式、来源指纹与离线运行方式。

## Risks / Trade-offs

- 步骤执行可能被误认成功 → 文案明确“已操作”不等于保存成功，回执单独显示。
- 自由试验偏离路线 → 显示刚做的动作及下一推荐步骤，不偷偷重置或强制补写。
- 辅助工具不易发现 → 使用有含义的区块标题和效果说明，保持可展开。
- 小屏三栏难读 → 保留相同阅读顺序，改为上下布局；主要状态摘要位于操作结果附近。

## Migration Plan

更新现有 PR #2 的入口与说明，快进提交，不改 main 或其他原型分支。原版与单栏版均由 Git 历史保留。
